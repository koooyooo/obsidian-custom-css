## General

A simple Obsidian theme inspired by Typora and GitHub.

## Usage

Copy the CSS file into the `${obsidian-vault}/.obsidian/snippets` directory.

## Other settings

### Themes

    Default

### Accent Color

    R: 66 G: 123 B: 184

### Interface font & Text font

    ヒラギノ角ゴシック

    > ヒラギノ角ゴシック will not appear in the list. Type the name and add it to make it available.

### Monospace font

    PT Mono
